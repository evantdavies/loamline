# Loamline

A 3D physics-based mountain bike downhill, dirt jump, and freeride game built with TypeScript, Vite, and Three.js.

## Quick Start

```bash
npm install
npm run dev
```

## Features

- **5 Handcrafted 3D Zones & 64 Tracked Challenges**:
  - **Training Hall** (7 tasks) — Sunlit timber skills arena with rollers, tabletops, berms, and drops.
  - **Jump Park** (8 tasks) — Golden-hour dirt jump line for big air, whips, barspins, tabletops, and backflips.
  - **Timber Shore** (14 tasks) — Coastal pine singletrack with wet mud pits, rock gardens, and elevated cedar bridges.
  - **Harbour Yard** (17 tasks + 13 Cargo Tags) — Industrial dockside freeride yard with rideable shipping containers, ramps, and cranes.
  - **Summit Line** (18 tasks) — High-altitude alpine descent with steep chutes, banked S-berms, mud bogs, bridges, and the Summit Road Gap.
- **Controls (Keyboard, Gamepad, Touch & Tilt Steering)**:
  - `W` / `↑` Pedal, `S` / `↓` Brake/Skid, `A` / `D` (`←` / `→`) Steer & Carve
  - `Space` Bunny Hop (Hold to preload, Release to pop)
  - `Shift` Pump rollers & crouch/attack position
  - `Q` / `E` (or `I` / `K`) Lean Back (Manual / Backflip) & Lean Forward (Nose / Frontflip)
  - `J` / `L` (or `Z` / `X`) Air Whip, `F` / `U` Barspin, `G` Tabletop
  - `C` Camera (`Helmet POV`, `Trail Chase`, `Close Action`)
  - `R` Checkpoint Reset, `Backspace` Full Restart, `T` / `Y` Session Marker
  - Full Gamepad + Mobile Touch Joystick & auto-calibrating Tilt Steering
- **My Garage**: Earn Credits to unlock 5 bikes (`Camber HT`, `Timber 150`, `Kicker DJ`, `Enduro 170`, `Ridge DH 200`), upgrade Fork/Shock/Tires/Brakes, and customize liveries live in 3D.
- **Replays**: Auto-records runs with Play/Pause, 0.25x–2x slow-motion, timeline scrubbing, and 4 replay cameras.
